Why rebuild a platform you can just log into

WorldQuant's BRAIN is a hosted research environment: you write expressions in its DSL, it simulates them server-side against a clean universe and returns a performance tab. It works well, and it means the parts that actually determine whether a factor is real — the neutralisation, the cost model, the correlation check against what you already have — are someone else's code.

brain_local reimplements that workflow locally so every one of those decisions is visible and changeable. It runs on one CPU against one pandas DataFrame, with no external services.

python -m brain_local.main

That generates a synthetic universe of 40 assets over roughly 600 trading days, builds every factor in the registry, and writes a full set of reports.

The parts that matter

Information coefficient, not backtest P&L, as the primary statistic. A cumulative return curve is one path; rank IC per date is a distribution, and it tells you whether a factor has any cross-sectional signal before position sizing flatters or destroys it.

Costs are in the loop, not applied afterwards. Turnover is computed per rebalance and charged through a linear basis-point model. A factor that looks good gross and dies net should die in the leaderboard, not in a footnote.

Correlation pruning is a first-class step. Twenty factors that are all momentum in disguise are one factor. The pipeline emits a factor-return correlation matrix, greedy clusters on absolute correlation, flags pairs above 0.9 as duplicates, and produces the pruned subset it would actually keep.

Stability is tested, not assumed. IC is recomputed per chronological block and separately in high- and low-volatility regimes. Factors that only work in one sub-period get flagged.

Being honest about the proxy

The README has a section titled "where we're only a proxy", which is the part I would point at first:

  • Universe — synthetic data, so there is no survivorship bias because there is no survivorship. A real loader must enforce point-in-time membership itself.
  • Costs — a single-bps linear model. Real impact is nonlinear; square-root or Almgren–Chriss would replace it.
  • Neutralisation — demeaning within sector groups only, against BRAIN's richer industry, subindustry and country combinations.

A research tool that overstates its own fidelity is worse than no tool, because it launders assumptions into results.

Scaling out

The synthetic data generator sits behind the same interface a real loader would. Swapping it and pointing the sweep engine at a larger grid is the intended path from toy to real; nothing else in the pipeline assumes the universe is small.
